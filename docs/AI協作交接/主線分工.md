# iKey v3.1｜主線分工

> 此頁記錄目前交接對話確認的責任邊界；具體工作項目仍需與各主線最新程式及交接紀錄核對。

| 主線 | 主要職責 |
| --- | --- |
| M1 | 網站前端、登入與帳號介面、專案管理、iBOX 裝置頁、開鎖操作 UI、公告與通知、動畫 |
| M2 | Render 伺服器與 API |
| M3 | ESP32 韌體及通訊 |
| M4 | Google Apps Script／Google Sheets |
| M5 | iBOX 實體硬體與鎖控 |
| M6 | 權限、安全與異常處理 |

## 協作規則
- M1 可以提出 API 契約與前端整合修正，但不得默認接管 M2/M4 的部署。
- 本次公告任務跨 M1、M2、M4、M6；修改必須明確註明影響範圍。
- 舊版課表、教室、固定八格鑰匙櫃功能不列入 v3.1 現行 M1 規格。
