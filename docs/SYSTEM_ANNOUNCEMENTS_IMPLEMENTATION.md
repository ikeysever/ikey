# iKey 3.1 系統公告｜實作歷程

## 2026-11-02｜第 14 項：首頁公告排序核心

### 已採用的排序基準
- 第一排序鍵：公告優先級，緊急（urgent）> 重要（important）> 一般（normal）。
- 第二排序鍵：同優先級時，發布時間（published_at）由新到舊。
- 第三排序鍵：發布時間相同或缺漏時，以建立時間（created_at）由新到舊。
- 無法辨識的優先級排在已知優先級之後；無效／缺漏時間不會被當成最新公告。
- 排序函式回傳新陣列，不修改原始資料。

### 本次程式變更
