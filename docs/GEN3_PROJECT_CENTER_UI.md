# iKey Gen3｜專案中心前端第一版交接紀錄

更新日期：2026-10-14

## 本次交付範圍

- 左側「專案中心」標題可進入專案中心首頁，同時維持原本可展開的側欄。
- 首頁：專案申請、我的專案兩個入口。
- 專案申請：建立專案、加入專案、申請紀錄三個可切換分頁。
- 我的專案：選擇專案後才顯示專案總覽、iBox 管理、成員管理、專案設定、設定審核、操作歷程六個分頁。
- 目前僅提供**明確標示的示範專案**，不是正式專案資料。
- 響應式版面、鍵盤分頁導覽及畫面預覽提示。

## 已確認並遵循的專案規則

- PM-13 B：有 iBox 關聯的專案可提出刪除申請，由超級管理員審核。
- PM-14 A：升任專案管理員需本人接受。
- PM-15 C：邀請碼期限由管理員設定，受系統上限限制。
- PM-16 A：刪除核准後封存，保留歷史。
- PM-17 B：最後一位管理員可離開，改由超級管理員接管。
- PM-18 B：iBox 操作類型分別授權。
- PM-19 C：邀請碼可選擇直接加入或審核加入。
- PM-20 A：無管理員時，既有 iBox 授權維持，暫停一般授權變更。
- PM-21 C：一般借還授權可直接生效，高風險開鎖等授權需超級管理員核准。

## 安全與未完成項目

本次**只變更前端頁面**，沒有建立或修改專案 API、Google Sheet 欄位、Apps Script、ESP32 指令或任何使用者/設備授權。建立與加入按鈕暫時停用，申請紀錄與專案清單不會顯示虛構資料。示範專案僅供查看六分頁布局，沒有正式操作權限。

後續應依已確認的權限規格逐項開發：專案清單讀取、建立申請五步驟、邀請碼與申請審核、成員升任、iBox 權限與審核、操作歷程。不得以示範前端狀態代替後端權限檢查。
