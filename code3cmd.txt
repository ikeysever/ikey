iKey 協作進度板 — code3cmd
========================================
分支：3
負責：LINE 製作子分支
用途：讓其他開發對話/組員知道 LINE 分支目前正在修改什麼、做到哪裡，以及是否可能與其他程式衝突。

【共同協作規則】
1. 每次修改 GitHub 程式前，先查看 repo 最新 HEAD、目標檔案最新 SHA，以及 code1cmd / code2cmd / code3cmd 的最新內容。
2. 發現其他分支剛 Push 時，不使用舊版本覆蓋；重新讀取最新檔案後再修改。
3. 每次修改後，在本進度板留下：
   - 日期
   - 狀態（進行中 / 已完成 / 待測試 / 暫停）
   - 正在修改的功能
   - 修改的檔案
   - GitHub commit
   - 已完成內容
   - 下一步
   - 與其他分支的衝突注意事項
4. code1cmd 由「睿謙的程式」分支維護。
5. code2cmd 由「動畫製作需求」分支維護。
6. code3cmd 由「LINE 製作子分支」維護。
7. 不代替其他分支填寫其實際開發進度，避免狀態失真。

【2026-10-07｜LINE 登入／換帳號規則確認】
狀態：規格已確認，程式尚未實作

使用者正式確認：
- 同一個 LINE 帳號已登入 iKey 身分後，不允許直接切換／覆蓋成另一個學生或老師身分。
- 若要改登入另一個 iKey 身分，必須先「登出」目前身分，再重新登入。
- 因此後續正式綁定流程不可設計成直接覆蓋既有綁定。

預定流程：
已登入 iKey 身分
→ 帳號管理顯示目前登入資料
→ 若要換身分，先按「登出」
→ 登出完成
→ 才重新開放「登入」
→ 選擇學生／老師
→ 找到既有 Users 身分
→ 確認後進行正式 LINE 綁定

待下一步確認／實作：
- 「登出」時實際需要清除或更新哪些既有 LINE 綁定欄位，會依目前 Users / Apps Script 已有欄位與 API 能力實作，不自行新增資料欄位。
- 正式實作前仍需重新讀取 main 最新 HEAD、routes/line.js 最新 SHA，以及三份 cmd 進度板。

衝突注意：
- 本次只更新 code3cmd 規格紀錄，沒有修改 routes/line.js、database.js、Apps Script、Borrow/Return 或 ESP32。
