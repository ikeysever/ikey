iKey 協作進度板 — code3cmd
========================================
分支：3
負責：LINE 製作子分支
用途：讓其他開發對話/組員知道 LINE 分支目前正在修改什麼、做到哪裡，以及是否可能與其他程式衝突。

【共同協作規則】
1. 每次修改 GitHub 程式前，先查看 repo 最新 HEAD、目標檔案最新 SHA，以及 code1cmd / code2cmd / code3cmd 的最新內容。
2. 發現其他分支剛 Push 時，不使用舊版本覆蓋；重新讀取最新檔案後再修改。
3. 每次修改後，在本進度板留下：
   - 日期
   - 狀態（進行中 / 已完成 / 待測試 / 暫停）
   - 正在修改的功能
   - 修改的檔案
   - GitHub commit
   - 已完成內容
   - 下一步
   - 與其他分支的衝突注意事項
4. code1cmd 由「睿謙的程式」分支維護。
5. code2cmd 由「動畫製作需求」分支維護。
6. code3cmd 由「LINE 製作子分支」維護。
7. 不代替其他分支填寫其實際開發進度，避免狀態失真。
