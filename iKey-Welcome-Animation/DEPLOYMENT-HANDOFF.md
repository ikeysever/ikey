# 給負責上架聊天的交接文

請接手「iKey 自動多場景智慧鎖」的登入成功歡迎動畫整合。使用者已確認最新版 MP4 與 HTML 預覽，並授權把素材與程式放入 GitHub 交接資料夾；正式上架請按專案既有流程執行。

Repository：`ikeysever/ikey`。交接分支：`handoff/welcome-padlock-20261009`。資料夾：`iKey-Welcome-Animation/`。先讀 `HANDOFF.md`，再查看 `preview/welcome-self-contained.html` 與 `preview/welcome-preview.mp4`。單檔 HTML 已內嵌字體及聲音；正式整合以採用相對路徑的 `preview/welcome-preview.html` 為程式參考。Python 腳本僅用於輸出影片，不是正式網站播放模組。

最新版畫面是掛鎖與真正鑰匙輪廓，齒口朝上，鑰匙插入部分不可透視。最後圖標同時呈現掛鎖與完整鑰匙，邊界較重。背景沿用登入頁的深藍 radial-gradient；桌面為圖標、垂直分隔線、文字的左右排版，手機為上下排版。

最後文字與出場順序已確認：圖標於 6.90 秒定位完成 → 分隔線於 7.40 秒完成 →「歡迎使用 iKey」於 7.55–8.15 秒淡入 →「自動多場景智慧鎖」於 8.15–8.75 秒淡入。影片全長 9.80 秒，1920×1080、60 FPS、含聲音，末段停留完整構圖。不要使用舊的「智慧鑰匙管理系統」或「智慧鑰匙倉儲管理系統」。前段黑色字形輪廓已修正，未到文字出場時間不可繪製文字。音軌保留目前已確認版本。

此分支只交付預覽與素材，尚未合併 main、接正式登入流程或部署。請先同步最新 main、閱讀專案進度紀錄及適用的 AGENTS.md，保留既有課表、角色導覽、LINE、API 等功能。不要整個交接分支覆蓋正式網站，也不要同時播放新舊歡迎動畫。新版以 Canvas 原生畫法呈現，不使用舊的指紋、Cloud、LINE、八格素材。

整合時移除預覽控制項，接入現有登入成功生命週期。預覽的「8.8 秒載入成功」是假資料演示，正式必須等待動畫完成條件與真實首頁資料準備兩者達成才进入首頁；慢載入、失敗重試與減少動態設定均需處理。收尾和弦應拆為可由真實資料就緒事件觸發的段落，不能拿整段音軌代替載入判斷。音訊須遵守使用者操作啟動限制，播放失敗仍能完成無聲畫面。離開、重播或重複登入時清除動畫、音訊、事件與 DOM。

保留 fonts/OFL.txt。新增 project-title-subset.ttf 是新題目的字型子集，不是完整中文字型。MP4 是 Python/Pillow 輸出，不是瀏覽器錄屏，線條與字型細節可能略有差異。已確認編碼規格、關鍵影格、字形與 JavaScript 語法；尚未完成真實瀏覽器、實機手機、聲音聆聽、正式登入或首頁資料整合驗收。也尚未製作獨立全站 Logo／favicon。
