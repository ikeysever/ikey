【協作規則】
==================================================
1. 本檔由「動畫製作需求」工作線維護。
2. 每次準備修改 GitHub 程式前，先讀取 main 最新版本與 code1cmd.txt / code2cmd.txt / code3cmd.txt。
3. 開始修改時，先在本檔記錄「目前正在修改」。
4. 修改完成後，更新「完成內容、影響檔案、Commit、目前狀態、下一步」。
5. 不使用舊版完整檔案直接覆蓋 GitHub 最新版。
6. 若發現其他工作線剛修改同一檔案或同一功能，先停止覆蓋並重新讀取最新版後合併。
7. code1cmd.txt = 睿謙的程式
8. code2cmd.txt = 動畫製作需求
9. code3cmd.txt = LINE 製作子分支
